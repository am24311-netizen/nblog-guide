3분 요약

처음 한 번만 설정하면, 다음부터는 [실행] 버튼만 누르시면 됩니다.

  1. 압축을 풀고 실행

    NaverAutomationUI.exe 를 두 번 클릭합니다.

  2. API 키 넣기

    왼쪽 [4 계정/API] → [🔑 API 키 설정] → OpenAI 키 붙여넣기 → [설정 저장]

  3. 네이버 로그인

    같은 화면의 [네이버 로그인] 을 눌러 한 번 로그인해 둡니다.

  4. 첫 글 올리기

    왼쪽 [1 실행] → 키워드와 블로그ID 입력 → [실행 (단일 발행)]

다 되면 이렇게 나옵니다 진행 상태의 동그라미 5개가 모두 채워지고 “발행 성공 🎉” 이 뜹니다.

1. 설치하기

  1. 파일 받기

    아래 다운로드 에서 ZIP 파일을 받습니다.

  2. 압축 풀기

    ZIP 을 우클릭 → 압축 풀기. 고정된 폴더에 푸시는 걸 권합니다. 예: C:\NaverAutomation\

    폴더 안에 이 파일들이 있으면 정상입니다.

  3. 실행

    NaverAutomationUI.exe 를 두 번 클릭합니다.

윈도우 보안 경고가 뜨면 [추가 정보] → [실행] 을 누르세요. 코드 서명이 없는 프로그램이라 나오는 안내이며, 한 번 실행하면 다음부터는 뜨지 않습니다.
ZIP 안에서 바로 실행하지 마세요 압축을 풀지 않고 실행하면 동작하지 않습니다. 반드시 압축을 푼 뒤 실행하세요.

라이선스 키가 없다면 — [가입 신청]

프로그램은 라이선스 키가 있어야 켜집니다. 키가 없으시면 프로그램 안에서 바로 신청하실 수 있습니다.

  • [라이선스 키 입력] 옆의 [가입 신청] 을 누릅니다.
  • 이름과 연락처를 넣고 확인을 누르면, 판매자에게 보낼 글이 복사됩니다.
  • 그 글을 판매자에게 그대로 보내시면 됩니다. 카카오톡에 붙여넣기만 하시면 됩니다.
  • 키를 받으시면 [라이선스 키 입력] 에 붙여 넣으세요.

2. 화면 둘러보기

프로그램을 켜면 대시보드가 먼저 나옵니다. 지금 상태를 한눈에 보는 화면입니다.

지금 상태라이선스 남은 기간 · 다음 예약 시각 · 오늘 발행한 건수
바로 가기각 화면으로 한 번에 이동합니다.
도움말이 가이드와 제휴사 공식 사이트를 바로 엽니다.

왼쪽 목록 — 위에서 아래로 한 번씩

1 실행무엇을 쓸지 정하고 실행하는 곳. 평소에 쓰는 화면입니다.
2 글 설정어떤 AI로 글을 쓸지 정합니다.
3 발행 규칙언제, 몇 건이나 올릴지 정합니다.
4 계정/APIAPI 키와 네이버 로그인.
맨 아래 흰 칸은 진행 기록입니다 어느 화면에 있든 항상 보입니다. 실행하면 지금 무엇을 하는 중인지 여기에 한글로 나옵니다. 문제가 생겼을 때 가장 먼저 볼 곳입니다.

3. API 키 넣기

글을 쓰려면 AI 키가 최소 하나 있어야 합니다. 나머지는 없어도 발행됩니다.

키필요 여부어디서 받나
OpenAI API Key필수 — 글을 씁니다platform.openai.com
Pixabay API Key권장 — 무료 사진pixabay.com/api/docs
Anthropic / Gemini선택 — 다른 AI로 바꿀 때각 사이트
Google Search / CSE선택 — 참고 자료 수집Google Cloud
네이버 검색 Client선택 — 없어도 발행 정상developers.naver.com
쿠팡파트너스선택 — 쿠팡 자동 모드파트너스 > 도구 > Open API

넣는 방법

  1. 키를 복사합니다. (발급 사이트에서 Copy)
  2. 해당 칸 옆의 [붙여넣기] 를 누릅니다.
  3. 잘 들어갔는지 보려면 [보기], 지우려면 [지우기].
  4. 왼쪽 아래 [설정 저장] 을 누릅니다. 이걸 안 누르면 저장되지 않습니다.
키는 앞뒤 공백 없이 공백이나 따옴표가 섞이면 인식되지 않습니다. [붙여넣기] 버튼을 쓰시면 안전합니다.

그 아래 [로그인 브라우저 관리] 는 무엇인가요

[ChatGPT 열기] [Claude 열기] [Gemini 열기] [Flow 열기] 버튼이 있습니다. API 키 대신 웹사이트에 직접 로그인해서 글을 쓰게 할 때 씁니다. 버튼을 누르면 그 사이트가 열리고, 거기서 한 번 로그인해 두면 프로그램이 그 창을 씁니다.

평소에는 안 쓰셔도 됩니다 API 키를 넣으셨다면 이 버튼들은 건드릴 일이 없습니다. 키 없이 쓰고 싶거나, 구독 중인 계정을 그대로 쓰고 싶을 때만 쓰는 길입니다.
API 키는 비밀번호와 같습니다 화면을 캡처해서 남에게 보내실 때는 키가 보이는 부분을 반드시 가려주세요.

4. 네이버 로그인

[4 계정/API] 화면의 [네이버 로그인] 을 누르면 크롬 창이 열립니다. 평소처럼 로그인하시면 됩니다. 처음 한 번만 하면 됩니다.

  1. 크롬을 모두 닫습니다

    같은 프로필을 쓰는 창이 열려 있으면 잠겨서 실패합니다.

  2. [네이버 로그인] 클릭

    크롬 창이 새로 열립니다.

  3. 네이버에 로그인

    2단계 인증이 있으면 그것까지 마칩니다.

  4. 창을 닫습니다

    프로그램이 로그인 정보를 기억합니다.

다음부터는 자동입니다 로그인 정보가 보관되어 발행할 때 자동으로 들어갑니다. 가끔 풀리면 같은 방법으로 다시 로그인하시면 됩니다.

5. 첫 발행 해보기

  1. 실행 모드

    정보성 키워드 를 고릅니다. (처음에는 이게 가장 쉽습니다)

  2. 정보성 키워드

    쓰고 싶은 주제를 넣습니다. 예: 여름철 제습기 관리법

  3. 블로그ID

    본인 블로그 주소의 아이디입니다. blog.naver.com/여기

  4. 이미지 개수

    처음에는 1 ~ 2 정도로 시작하세요.

  5. [실행 (단일 발행)] 클릭

    크롬이 열리고 3~5분 정도 걸립니다.

키워드를 여러 개 쌓아두려면 [정보 키워드 편집] 을 누르면 메모장이 열립니다. 한 줄에 하나씩 적어두세요. 실행할 때마다 위에서부터 하나씩 꺼내 씁니다. 성공한 키워드는 목록에서 사라집니다.

키워드에 상품 링크를 같이 붙이고 싶다면 — 정보엑셀

정보성 모드에서만 보이는 [정보엑셀 경로] 줄입니다. 메모장 대신 엑셀로 관리하는 방법이며, 키워드 옆에 상품 링크를 같이 적어둘 수 있습니다. 글 끝에 그 링크가 들어갑니다.

칸무엇을 적나
정보성키워드쓰고 싶은 주제. 예: 여름철 제습기 관리법
상품링크글에 넣을 상품 주소. 비워두셔도 됩니다 — 그러면 링크 없이 나갑니다

[찾기] 로 엑셀 파일을 고르고, [열기/편집] 을 누르면 그 파일이 바로 열립니다. 줄을 채우고 저장한 뒤 실행하면 위에서부터 하나씩 꺼내 씁니다.

메모장과 엑셀 중 하나만 쓰시면 됩니다 링크가 필요 없으면 [정보 키워드 편집](메모장)이 더 간단합니다. 링크를 같이 넣고 싶을 때만 정보엑셀을 쓰세요.
실행 중에는 크롬 창을 건드리지 마세요 프로그램이 크롬을 직접 조작합니다. 중간에 클릭하거나 창을 닫으면 실패할 수 있습니다. 다른 일을 하셔야 하면 다른 브라우저를 쓰세요.
처음에는 꼭 1건만 글이 마음에 드는지, 사진이 잘 붙는지 확인한 뒤에 개수를 늘리세요.

7. 싹된다에서 바로 발행하기

싹된다(쿠팡 로켓배송 프로그램)를 함께 쓰시면, 블로그 화면을 따로 익히지 않아도 싹된다에서 버튼 하나로 글이 나갑니다.

순서어디서무엇을
1싹된다 · 광고 · 홍보팔리는 상품을 고르고 글 조건(글 수 · 사진)을 정합니다
2싹된다 · 맨 위 [위치 지정]처음 한 번만 — 이 프로그램(NaverAutomationUI.exe)이 어디 있는지 알려 줍니다
3싹된다 · [블로그로 바로 발행]후기 엑셀을 만들고 이 프로그램을 켭니다
4이 프로그램받은 엑셀을 읽어 바로 발행을 시작합니다
발행 조건은 이 프로그램 설정을 그대로 씁니다 계정 · 발행 간격 · 예약 시간은 발행 규칙과 [4 계정/API] 화면에 넣어 둔 값으로 나갑니다. 싹된다가 정하는 것은 어떤 상품으로 몇 편을 쓸지까지입니다.

시작이 안 될 때 — 진행 기록에 이유가 나옵니다

  • “파일을 찾지 못했습니다” — 싹된다에서 블로그 파일을 다시 만들어 주세요.
  • “이미 발행 중입니다” — 지금 실행이 끝난 뒤 다시 눌러 주세요.
  • “발행할 줄이 없습니다” — 그 엑셀은 이미 다 썼거나 비어 있습니다.

같은 내용이 싹된다 화면에도 그대로 표시되므로, 어느 쪽을 보셔도 됩니다.

양쪽에 따로 넣어야 하는 것 싹된다에 넣은 API 키는 이 프로그램으로 오지 않습니다. 글쓰기용 AI 키는 이 프로그램에도 따로 넣어야 하고(API 키 넣기), 네이버 로그인도 이 프로그램에서 직접 한 번 해 두셔야 합니다(네이버 로그인).
발행할 때는 이 프로그램을 닫아 주세요 이미 켜져 있으면 같은 네이버 기록을 두 곳에서 쓰게 되어 싹된다가 발행을 시작하지 못합니다.

8. 글 설정 — 어떤 AI로 쓸까

  • 원고 생성 엔진 — 기본은 OpenAI 입니다. 넣어둔 키에 맞춰 고르세요.
  • 외부기사 참고 — 켜면 관련 기사를 찾아 참고합니다. (네이버 검색 키 필요)
  • 고급 옵션 — 평소에는 접어두셔도 됩니다. 세부 설정과 프롬프트 편집이 들어 있습니다.
기본값이 가장 무난합니다 잘 모르시겠으면 손대지 마세요. 기본 설정으로도 잘 나옵니다.

글이 나가기 전에 자동으로 하는 것

따로 켜고 끄실 것은 없습니다. 발행 직전에 프로그램이 스스로 다듬습니다.

  • 문법 검사 — 문법·맞춤법이 어색한 문장을 고칩니다.
  • 읽기 좋게 정리 — 긴 문단을 끊고 요약·강조 덩어리를 넣어 모바일에서 읽기 편하게 만듭니다.
  • 금지어 확인 — 광고로 문제될 수 있는 표현을 걸러냅니다.

9. 사진 넣기

사진은 [1 실행] 화면의 이미지 칸에서 정합니다.

정보 이미지폴더정보 글에 쓸 사진이 든 폴더
상품 참고 이미지폴더후기 글에 쓸 상품 사진 폴더
이미지 개수한 편에 몇 장 넣을지. 예: 1 ~ 2
사진이 없어도 발행됩니다 폴더가 비어 있으면 무료 사진(Pixabay)에서 찾거나, 사진 없이 올립니다. 사진 때문에 발행이 막히지는 않습니다.
같은 사진이 반복되지 않습니다 이미 쓴 사진을 기억해서 다시 쓰지 않습니다. 폴더에 사진을 넉넉히 넣어두세요.

10. 스토어몰 링크 · 쿠팡파트너스

상품 링크를 글에 넣고 싶을 때만 씁니다. 안 쓰셔도 됩니다.

일반 스토어 링크기본값. 링크만 넣습니다.
네이버 쇼핑커넥트네이버 브랜드 커넥트 링크를 쓸 때
쿠팡파트너스쿠팡 수익 링크를 쓸 때
쿠팡파트너스를 쓰신다면 꼭 읽어주세요 쿠팡파트너스 링크가 들어간 글에는 대가성 안내 문구가 반드시 들어가야 합니다. 넣지 않으면 파트너스 활동이 정지될 수 있습니다.

그래서 [쿠팡파트너스] 를 고르면 안내 문구 넣기가 자동으로 켜지고, 끌 수 없게 잠깁니다. 불편해 보여도 사장님 계정을 지키기 위한 장치입니다.

쿠팡파트너스 정책과 가입 방법은 공식 사이트가 가장 정확합니다. 프로그램 대시보드 → [쿠팡파트너스 공식] 버튼으로 바로 갈 수 있습니다.

왜 저희가 따로 안 만드나요 제휴 정책은 자주 바뀝니다. 저희가 베껴 적어두면 낡은 정보가 남아 오히려 위험합니다. 그래서 공식 사이트로 바로 연결합니다.

11. 발행 규칙 — 언제 올릴까

발행 시간대이 시간 안에서만 올립니다. 예: 09~23시
주말 감소주말에는 건수를 줄입니다.
일일 상한하루 최대 몇 건까지 올릴지
시작 지연실행 후 조금 기다렸다 시작합니다.
네이버 발행즉시 발행 / 예약 발행을 고릅니다.
왜 이런 게 있나요 사람이 쓰는 것처럼 자연스럽게 올리기 위해서입니다. 짧은 시간에 몰아서 올리면 블로그에 좋지 않습니다.
“아무것도 안 하고 끝났어요” 라고 나온다면 발행 시간대 밖이라 건너뛴 것일 수 있습니다. 진행 기록에 “지금은 발행 시간대가 아니에요” 라고 나옵니다. 시간대를 넓히시거나, 그 시간에 실행하세요.

13. 업데이트

[1 실행] 화면 아래쪽의 [업데이트 확인] 버튼을 누르면 새 버전이 있는지 확인합니다.

  • 버튼 옆에 지금 쓰시는 버전이 표시됩니다.
  • 새 버전이 있으면 안내창이 뜹니다. 안내대로 진행하시면 됩니다.
  • 업데이트 중 문제가 생기면 이전 버전으로 자동 복구됩니다.
업데이트해도 지워지지 않는 것 API 키, 라이선스, 설정, 네이버 로그인 정보, 키워드 목록, 작성 기록은 그대로 유지됩니다. 다시 넣지 않으셔도 됩니다.
자동으로 확인하지는 않습니다 프로그램이 켜질 때 스스로 확인하지 않습니다. 가끔 [업데이트 확인] 을 눌러보세요.

14. 이럴 땐 이렇게

실행했는데 아무 일도 안 일어납니다

맨 아래 진행 기록을 봐주세요. 이유가 한글로 나옵니다. 자주 나오는 것은 두 가지입니다.

  • 발행 시간대 밖 — 발행 규칙에서 시간대를 확인하세요.
  • 키워드가 비어 있음 — 키워드 칸이나 키워드 파일을 확인하세요.

“제목을 입력해주세요” 라고 나옵니다

네이버 글쓰기 화면이 덜 열린 상태에서 진행된 경우입니다. 크롬 창을 전부 닫고 다시 실행해 보세요.

사진이 안 붙습니다

  1. 이미지폴더 경로가 맞는지 확인하세요.
  2. 폴더에 사진이 실제로 있는지 보세요.
  3. 이미지 개수를 1 ~ 2 로 낮춰보세요.

사진이 없어도 글은 정상 발행됩니다.

로그인이 자꾸 풀립니다

[로그인 쿠키 삭제] → [네이버 로그인] 순서로 다시 해보세요. 크롬 창이 여러 개 떠 있으면 전부 닫고 하시는 것이 좋습니다.

프로그램 폴더를 다른 PC로 옮기면 보안상 로그인 정보가 초기화됩니다. 같은 PC 안에서 폴더 위치만 바꾸는 것은 괜찮습니다.

API 키를 넣었는데 저장이 안 됩니다

API 설정 창 왼쪽 아래의 [설정 저장] 을 눌러야 저장됩니다. 창을 그냥 닫으면 저장되지 않습니다.

글이 올라갔는데 제목과 내용이 안 어울립니다

프로그램이 제목과 본문이 어울리는지 검사해서, 안 맞으면 올리지 않고 멈춥니다. 그래도 어색하면 키워드를 더 구체적으로 적어보세요.

예: 제습기 → 여름철 제습기 관리법

실행이 오래 걸립니다

한 편에 3~5분이 정상입니다. 4 원고 단계에서 1~3분 머무릅니다. 10분이 넘어가면 진행 기록을 확인해 주세요.

그래도 해결이 안 되면

화면 아래 진행 기록을 캡처해서 보내주세요. 어느 단계에서 멈췄는지 보면 알 수 있습니다.

보내시기 전에 API 키가 보이는 부분은 반드시 가려주세요.
