1. 설치하기

  1. 배포 파일 받기

    전달받은 ZIP 파일을 바탕화면이 아닌 고정된 폴더에 풀어주세요. 예: C:\NaverAutomation\

  2. 압축 풀기

    ZIP을 우클릭 → 압축 풀기. 폴더 안에 다음 파일이 있으면 정상입니다.

    NaverAutomationUI.exe      <- 실행 파일
RunAllWorker.exe           <- 발행 담당 (직접 실행하지 마세요)
NaverAutomationUpdater.exe <- 자동 업데이트
version.txt
templates\  manual\
  3. 실행

    NaverAutomationUI.exe 를 더블클릭합니다.

윈도우 보안 경고가 뜨면 “추가 정보” → “실행”을 누르세요. 코드 서명이 없는 프로그램이라 나오는 안내입니다.

2. API 키 발급 및 입력

원고를 만들려면 AI API 키가 최소 1개 필요합니다.

키필요 여부발급처
OpenAI필수 (기본 엔진)platform.openai.com
Pixabay권장 (사진 자동 수집)pixabay.com/api/docs
Anthropic / Gemini선택 (엔진 교체용)각 사이트

입력 방법

  1. 프로그램 상단 [API 키 설정] 버튼 클릭
  2. 발급받은 키를 붙여넣기
  3. [설정 저장] 클릭
키는 = 뒤에 공백 없이 앞뒤 공백이나 따옴표가 들어가면 인식되지 않습니다.

3. 네이버 로그인

처음 한 번만 직접 로그인하면, 이후에는 자동으로 유지됩니다.

  1. [실행]을 누르면 크롬 창이 열립니다.
  2. 열린 창에서 네이버에 직접 로그인하세요.
  3. 로그인이 끝나면 프로그램이 자동으로 다음 단계를 진행합니다.
로그인 전에 크롬을 모두 닫아주세요 같은 프로필을 쓰는 크롬 창이 여러 개 열려 있으면 프로필이 잠겨 실행이 실패합니다. 작업 표시줄에서 크롬을 전부 종료한 뒤 실행하세요.

4. 첫 발행 해보기

  1. 키워드 입력 — 예: “전기요금 절약”
  2. 발행 개수 — 처음에는 1개로 시작하세요.
  3. [실행] 클릭
  4. 로그 창에 naver_publish=1 이 뜨면 발행 성공입니다.
처음에는 꼭 1건만 글이 마음에 드는지, 사진이 잘 붙는지 확인한 뒤 개수를 늘리세요.

5. 글 유형 3가지

유형내용필요한 것
정보성키워드 기반 정보 글키워드만
상품 후기상품 리뷰 형식키워드 + 상품 URL
상품 대량여러 상품을 순차 발행상품링크 파일

혼합 모드에서는 위 세 가지 비율을 정해 섞어서 발행할 수 있습니다.

6. 자동 업데이트

프로그램이 켜질 때 새 버전이 있는지 자동으로 확인합니다.

  • 새 버전이 있으면 안내창이 뜹니다.
  • [업데이트]를 누르면 프로그램이 종료됐다가 자동으로 다시 켜집니다.
  • 업데이트 중 문제가 생기면 이전 버전으로 자동 복구됩니다.
업데이트해도 지워지지 않는 것 API 키(secrets.env), 라이선스(license.key), 설정(settings.json), 로그인 정보, 작성한 글 기록은 그대로 유지됩니다.

7. 문제가 생겼을 때

제목이 비어 있다고 나옵니다

네이버 편집기가 늦게 뜬 경우입니다. 크롬을 모두 닫고 다시 실행해 주세요.

사진이 안 붙습니다

Pixabay 키가 없거나, 해당 키워드에 맞는 사진이 없는 경우입니다. 사진 없이도 글은 정상 발행됩니다.

로그인이 자꾸 풀립니다

프로그램 폴더를 다른 PC로 옮기면 보안상 로그인 정보가 초기화됩니다. 같은 PC 안에서 폴더 위치를 바꾸는 것은 괜찮습니다.

API 키가 사라졌습니다

[API 키 설정]에서 다시 입력한 뒤 [설정 저장]을 눌러주세요.

그래도 해결이 안 되면

화면 아래 로그 창 전체를 복사해서 전달해 주세요. 원인 파악에 꼭 필요합니다.
